# Uzbek Halva & Dry Fruits — сайт

Статический сайт на HTML/CSS/JS с одним PHP-скриптом для отправки отзывов в Telegram.
Языки: русский, английский, узбекский (переключатель в шапке).

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Главная |
| `about.html` | О компании |
| `products.html` | Ассортимент (баннеры категорий) |
| `feedback.html` | Обратная связь (форма отзыва) |
| `assets/js/i18n.js` | Все тексты на трёх языках |
| `assets/js/layout.js` | Шапка, подвал и **контакты** (телефон, Telegram, Instagram) |
| `assets/js/feedback.js` | Логика формы |
| `assets/img/cat-*.jpg` | Картинки баннеров категорий — замените на фото товаров с тем же именем |
| `api/feedback.php` | Принимает отзыв и пересылает его в Telegram |

## Подключение Telegram

1. В Telegram откройте **@BotFather** → `/newbot` → получите **токен** бота.
2. Решите, куда будут приходить отзывы:
   - **в личку** — напишите своему боту любое сообщение;
   - **в группу** — добавьте бота в группу и отправьте там любое сообщение.
3. Узнайте **chat_id**: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id": ...}`. У групп id начинается с `-100`.
4. Скопируйте `api/config.example.php` в `api/config.php` и впишите `bot_token` и `chat_id`.
5. Загрузите сайт на хостинг с **PHP 7.4+** и расширением **curl** (есть почти на любом хостинге).

Токен хранится только на сервере в `api/config.php` — в браузер он не попадает.
Файл `api/.htaccess` закрывает конфиг от просмотра (для Apache). На nginx закройте доступ к `api/config.php` в конфигурации сервера.

### Защита от спама
- скрытое поле-ловушка для ботов;
- не больше 5 отзывов с одного IP за 10 минут (меняется в `config.php`).

## Перед запуском заменить
- телефон, ссылки Telegram и Instagram — в начале `assets/js/layout.js`;
- адрес и часы работы — ключи `footer.address` и `footer.hours` в `assets/js/i18n.js`;
- картинки категорий `assets/img/cat-*.jpg` — сейчас это кадры из фото магазина.

## Локальный запуск

```bash
php -S localhost:8000
```

Затем откройте http://localhost:8000. Без PHP (например, через `python3 -m http.server`) сайт откроется, но форма отзыва выдаст ошибку отправки.
